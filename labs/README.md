# Experimental labs

ReasonedOps v1.4.4 remains frozen. This directory contains side experiments that are **not** part of the published `reasoned-ops` package or its frozen v1 API.

## ReasonedTrace

[`reasoned_trace/`](reasoned_trace/README.md) explores an append-only provenance ledger for observable human–AI decision workflows: model proposal, evidence/tool activity, policy checks, human review or override, and the final effective output.

The lab records observable application events and does not claim access to hidden model chain-of-thought.
